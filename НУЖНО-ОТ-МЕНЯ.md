# Что нужно от заказчика

## Обязательно (без этого не проверить в Telegram)
1. **Токен бота** — создать бота в @BotFather (`/newbot`), прислать токен. В BotFather там же: `/newapp` или Bot Settings → Menu Button — агент подскажет URL.
2. **Твой Telegram ID** — для доступа к админке (узнать у @userinfobot).

## Желательно
3. **Название и стиль** — есть ли идея названия, любимые цвета, приложения, которые нравятся по дизайну. Если нет — агент предложит 3 варианта.
4. **Ключ API спортивных данных** (бесплатный тариф The Odds API или API-Football) — для реальных матчей. Без него работает генератор.
5. **Хостинг** для постоянной работы: VPS (от ~2 ГБ RAM) + домен с HTTPS. Для разработки хватит туннеля на компьютере.

## Решить позже
6. Реальные деньги: юрисдикция и лицензия (в РФ — лицензия букмекера + ЦУПИС), платёжный провайдер.
