# VOLTA — ставки на спорт в Telegram (демо)

Telegram Mini App + бот. Ставки делаются на виртуальные монеты, которые нельзя купить или вывести. Матчи симулируются на сервере, коэффициенты в лайве пересчитываются в реальном времени.

## Запуск

Нужен Node.js 22+ (используется встроенный `node:sqlite`).

```bash
npm install
npm run build      # собрать фронтенд в apps/web/dist
npm start          # сервер + бот на http://localhost:3000
```

Разработка с горячей перезагрузкой: `npm run dev` (Vite на 5173, API на 3000).
Тесты: `npm test`.

С `DEV_AUTH=true` приложение открывается в обычном браузере без Telegram: http://localhost:3000.

## Настройки (`.env`)

| Переменная | Что делает |
|---|---|
| `BOT_TOKEN` | токен от @BotFather. Файл `.env` в git не попадает |
| `ADMIN_IDS` | Telegram ID админов через запятую. Админка — вкладка «Профиль» → «Админка» |
| `PUBLIC_URL` | публичный HTTPS-адрес Mini App. Пока пусто, бот отвечает текстом без кнопки «Играть» |
| `DEV_AUTH` | вход без Telegram. **Автоматически выключается, если задан `PUBLIC_URL`** |
| `LIVE_SPEED` | во сколько раз быстрее реального времени идут матчи |
| `FOOTBALL_DATA_KEY` | ключ football-data.org (бесплатный): включает раздел «Реальные матчи» — ставки до начала, расчёт по итоговому счёту |
| `TG_PROXY` | прокси до api.telegram.org (сейчас `http://127.0.0.1:10809`). Node не берёт системный прокси сам |
| `REAL_MONEY_ENABLED` | должно быть `false`. При `true` сервер не запустится |

## Как открыть приложение в Telegram

Telegram открывает Mini App только по HTTPS. Варианты:

1. **Туннель** (быстро, для теста): cloudflared (`cloudflared tunnel --url http://localhost:3000`) или `ssh -R 80:localhost:3000 nokey@localhost.run`. Адрес из вывода записать в `PUBLIC_URL` и перезапустить сервер. Бесплатный адрес меняется при каждом перезапуске туннеля.
2. **Хостинг** (постоянно): VPS с Node 22, домен с HTTPS (Caddy или nginx + Let's Encrypt), `npm run build && npm start` под pm2 или systemd. Если сервер за пределами РФ, `TG_PROXY` не нужен.

3. **Hugging Face Spaces** (бесплатно): заполнить в `.env` `HF_USER` и `HF_TOKEN` (токен с правом write: huggingface.co → Settings → Access Tokens) и запустить `bash scripts/deploy-hf.sh`. Скрипт создаст Space, перенесёт секреты и выложит код. Space засыпает после 48 часов без посетителей, а при перезапуске база обнуляется. Если бот на HF не может связаться с Telegram, нужно развернуть `docs/telegram-relay.js` на Cloudflare Workers, записать его адрес в `TG_API_ROOT` и запустить скрипт ещё раз.

4. **Render** (бесплатно, `render.yaml` в корне): New → Blueprint → репозиторий с кодом, затем задать `BOT_TOKEN` и `ADMIN_IDS`. Адрес Render подставляет сам (`RENDER_EXTERNAL_URL`). Бот работает на вебхуке (`BOT_MODE=webhook`), поэтому сообщение в Telegram будит уснувший сервер. Диск на бесплатном тарифе стирается, поэтому включена резервная копия базы (`TG_BACKUP=true`). Бот хранит её закреплённым файлом в чате с первым админом, обновляет каждые 3 минуты и перед остановкой, а при старте восстанавливает. Сообщение с копией не удаляйте и не открепляйте. Админ должен один раз нажать у бота /start.

Один токен бота нельзя одновременно запускать в двух местах: перед запуском на хостинге остановите локальный сервер.

После запуска с `PUBLIC_URL` бот сам ставит кнопку меню «Играть» и кнопку в /start.

Username бота через API не меняется — только в @BotFather → /mybots → Edit Bot → Edit Username. Имя, описание, команды и аватарку сервер выставляет сам (аватарка: `apps/server/assets/avatar.jpg`).

## Устройство

```
apps/server   Fastify + node:sqlite + grammY
  src/sports/       модели видов спорта (футбол, хоккей, баскетбол, теннис, волейбол, CS2, Dota 2, MMA)
  src/engine/       pricing.ts — коэффициенты Монте-Карло с маржой; live.ts — лайв-движок, расписание, расчёт
  src/services/     кошелёк (журнал проводок), ставки, бонусы, достижения, пользователи
  src/routes/       REST API и админка
  src/ws.ts         WebSocket: лайв-коэффициенты, уведомления
  src/bot.ts        бот: /start, /balance, /bonus, /help, уведомления о расчёте ставок
  data/volta.db     база (создаётся сама)
apps/web      React 18 + Vite + Tailwind + framer-motion
```

- Деньги хранятся целыми числами (1 монета = 100). Каждое движение баланса записано в `ledger`.
- Коэффициенты считаются симуляцией матча с текущего счёта; в рынке с пушем и азиатских линиях учитываются возвраты и половинные исходы.
- После гола или важного момента рынки закрываются на несколько секунд.
- Авторизация в Telegram — проверка подписи `initData` на сервере.

## Чего нет в демо

- Реальных денег. Для них нужна букмекерская лицензия (в РФ — ФНС + ЦУПИС), KYC, платёжный провайдер. В коде есть только заглушка `PaymentProvider` в `services/wallet.ts`.
- Реальных матчей: события генерируются. Названия клубов настоящие, теннисисты и бойцы MMA вымышленные. Для реальной линии понадобится платный фид (например, odds API).
